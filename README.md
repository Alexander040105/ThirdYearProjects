### Data Mining (`first_semester/data_mining_sub/`)

A comprehensive exploration of data mining techniques and applications:

#### **Finals** (`Finals/`)
- **Association Rules** - Market basket optimization and transaction analysis
  - `association_rules.ipynb` - Foundational association rules concepts
  - `association_rules_strong_association_transactions.ipynb` - Identifying strong associations in transaction data
  - `association_rules_MarketBasketOptimization.ipynb` - Market basket optimization techniques
  - Datasets: Multiple grocery and market basket datasets (Groceries_dataset.csv, Market_Basket_Optimisation.csv, etc.)

- **Final Project** - Student Academic Risk Prediction
  - `finalProject.ipynb` & `finalProject copy.ipynb` - Jupyter notebooks for the main project
  - `visualizing_rapidminer_kmeans.ipynb` - K-means clustering visualization
  - `Students_Grading_Dataset.csv` & `Cleaned_Students_Grading_Dataset.csv` - Student performance datasets
  - `DataMining_StudentAcademicRisk_Bolante_Solis_Virata.rmp` - RapidMiner project file
  - `dataBaseSchema.sql` - Database schema for the project
  - `rapidMinerResults.csv` - Results from RapidMiner analysis

#### **Midterms** (`Midterms/`)
- **Midterm Activities** - Practical data mining exercises
  - Customer Churn Analysis
    - `Datamining_customer_churn.ipynb` - Jupyter implementation
    - `Datamining_customer_churn_Solis_Virata.py` - Python implementation
    - Customer churn dataset
  
  - Redmi Dataset Analysis - Mobile phone data analysis activities

- **Midterm Exam** - Airbnb data analysis projects
  - `airbnb_ratings.ipynb` - Ratings analysis and modeling
  - `airbnb_ratings_withpkll.ipynb` - Enhanced ratings analysis
  - `airbnb_price_label.ipynb` - Price prediction
  - `airbnb_instan_booking_label.ipynb` - Booking prediction
  - `airbnb_ratings_model.py` - Python model for ratings prediction
  - `Airbnb_Open_Data.csv` - Complete Airbnb dataset

#### **Prelims** (`Prelims/`)
- `titanic.ipynb` - Titanic dataset analysis
- `retail_store.ipynb` - Retail store data analysis
- Datasets: Titanic-Dataset.csv, TitanicDatasetCleaned.rmp

## 🚀 How to Use This Repository

1. **Data Mining Projects**: Open Jupyter notebooks in the `first_semester/data_mining_sub/` folder to explore data analysis examples
2. **Security Demonstrations**: Run Flask applications to see security implementations in action
3. **System Projects**: Execute batch scripts or compile C++ projects as needed
4. **Data Visualization**: Work through prelim activities in the `second_semester/data_viz/` folder
